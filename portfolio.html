GradeCalHub

GradeCalHub is a web application designed to help students efficiently calculate and track their academic grades. Built with a React front-end, it offers a responsive and intuitive user interface for seamless interaction. The backend, powered by Node.js, ensures robust data processing and secure communication between the client and server. Utilizing MongoDB Atlas for its database, GradeCalHub provides reliable data storage and retrieval, enabling users to easily manage their coursework and monitor their academic progress. This project demonstrates a full-stack development approach, highlighting skills in modern web technologies and cloud-based solutions.

MBTI Personality Chatbot

This chatbot was developed for CS 4742 (Natural Language Processing) utilizing a trained distilBERT model from Hugging Face's transformers API that takes in user input and predicts their personality type based on the analysis. The model was trained on a mix of dataset found on Kaggle, with most data synthetically generated through various means. During training, the model achieved an overall accuracy of 93% across all personality types with balanced representation for each category. The front-end implementation used Flask in combination with traditional HTML, JavaScript, and CSS.

KSU Spring 2024 Hackathon

I participated in the Spring 2024 Hackathon at Kennesaw State University. My team and I developed a solution to help deaf people and visual listeners connect more easily with their environment. Our original plan was to use an AR headset to capture the world around users and place text above each person's head who is currently talking near them. However, we pivoted since the AR headset display didn't look professional enough for demonstration purposes. We ended up using an Android app to simulate the AR experience instead. Using Android Studio, we developed the app to convert speech to text in real-time and used Google's Detect Faces API to locate the face of each speaker and position text above them.

8 Puzzle Simulator

This program was designed for the 2nd assignment in my CS 3642 (Artificial Intelligence) course. For this assignment, I created a program that solves the 8-puzzle problem using various search algorithms including depth-first, uniform-cost, best-first, and A*. After solving, the program displays the solution found by the chosen algorithm along with the number of moves taken to discover it and total time elapsed. Users can also choose any end state or have one selected randomly. The puzzle is fully playable so users can enjoy entertainment while improving cognitive skills.

CS 3642 Assignment #3

The third assignment for my CS 3642 (Artificial Intelligence) course required creating a perceptron capable of training itself to solve the three black squares problem and demonstrating its capabilities. I chose to demonstrate this with a movie prediction algorithm that would predict odds a user of a streaming app would enjoy a movie based on previously watched titles, using The Matrix as an example case study. I ran 5 tests to determine classification accuracy on the three black squares problem - each test had 16 possible states for a total of 80 states. Out of those 80 total states, 78 were correct predictions with only 2 false positives that incorrectly classified all blocks as dark when only 2 squares should be black and others white. This resulted in a 97.75% classification accuracy rate (78/80). Calculating the movie prediction perceptron's accuracy is subjective since whether someone would enjoy a movie depends on personal preference, so we cannot objectively determine if weights are accurate based solely on results. However, examining them reveals clear trends showing exactly what I aimed to produce from the perceptron.

Virtual Operating System

Semester project for CS 3502 where we created a virtual operating system from scratch coded in C++. The goal was to simulate our own simple operating system so we could better understand how real-world operating systems operate and complete both simple and complex tasks. Our OS takes basic instructions and completes operations based on those through processes. It is capable of running multiple processes across multiple simulated processing cores, with the number dependent on user configuration. To accomplish this, we created a virtual hard drive, virtual primary memory, virtual processor, virtual bootloader, and scheduler to place processes from our waiting queue onto available processors. All these components work together to form a functioning virtual operating system.
